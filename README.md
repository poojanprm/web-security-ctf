# 🚩 Web Security CTF

A **beginner/intermediate Web Security Capture The Flag (CTF)** challenge created as a hands-on cybersecurity learning project.

This is a standalone, browser-based challenge focused on web reconnaissance and client-side security concepts.

---

## 🎯 Objective

Investigate the web application, follow the available clues, and discover the hidden flag.

The challenge encourages players to explore the application, inspect its client-side logic, and understand how different pieces of information connect together.

---

## 🧠 Concepts Covered

- Web Reconnaissance
- HTML Source Inspection
- JavaScript Analysis
- Client-Side Authentication Logic
- LocalStorage
- URL Parameter Manipulation
- Base64 Encoding/Decoding
- Hidden Routes
- Decoy/Fake Flags
- Browser Developer Tools
- Client-Side Security

---

## 🏆 Difficulty

**Beginner / Intermediate**

This challenge is intended for learners who are beginning to explore Web Application Security and browser-based CTFs.

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Browser Developer Tools

---

## 🏗️ Architecture

This CTF is a **standalone client-side web application**.

- No backend server
- No database
- No API
- No external dependencies
- All challenge logic runs locally in the browser
